# Common Issues

Having issues? Here are some common problems and their solutions.

Don't see your problem here? Please [open an issue on GitHub](https://github.com/empriselab/mote/issues).

## Configuration

Problems occuring while updating Motes firmware or connecting it to WiFi.

### My network doesn't appear

Mote can only connect to 2.4 GHz networks. Make sure your router has the 2.4 GHz band is enabled.
