# mote-firmware

Embassy firmware for the RP2530 that runs mote.

## Build and Deploy

Requirements:
* [cargo](https://rustup.rs) (rust package manager)
* [go-task](https://taskfile.dev/installation/) (task runner)
* [probe-rs](https://probe.rs/docs/getting-started/installation/) (flasher / debugger)

From this folder, run

```
task deploy
```
